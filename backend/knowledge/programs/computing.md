## bscs
name: BS Computer Science
summary: A four-year degree covering the foundations of computing - programming, algorithms, data structures and how computer systems work. The broadest computing degree.
studies: programming fundamentals, object oriented programming, data structures and algorithms, databases, operating systems, computer networks, theory of computation, discrete mathematics, artificial intelligence
skills: programming, problem solving, logical thinking, software design
careers: software engineer, web and mobile developer, AI engineer, data scientist, researcher, any computing career
suits: students who enjoy programming and logic and want the widest choice of computing careers

## bsse
name: BS Software Engineering
summary: A four-year degree focused on building large, reliable software products in teams, from requirements to testing and maintenance.
studies: programming, software requirements, software design and architecture, software testing and quality, project management, web engineering, human computer interaction
skills: building software products, teamwork, design, testing, project planning
careers: software engineer, full-stack developer, QA engineer, product engineer, project manager
suits: students who like building apps and products with a team more than theory

## bsai
name: BS Artificial Intelligence
summary: A four-year degree on making computers learn from data and act intelligently - machine learning, deep learning and their applications.
studies: programming in Python, linear algebra, probability and statistics, machine learning, deep learning, computer vision, natural language processing, knowledge representation
skills: building machine learning models, mathematics, data handling, research and experimentation
careers: AI engineer, machine learning engineer, computer vision engineer, NLP engineer, AI researcher
suits: students who love maths and want to build programs that learn, and enjoy research and experiments

## bsds
name: BS Data Science
summary: A four-year degree on collecting, analysing and visualising data to answer real questions and support decisions.
studies: statistics, probability, programming in Python and R, databases and SQL, data mining, machine learning, data visualisation, big data
skills: data analysis, statistics, visualisation, programming, communicating findings
careers: data scientist, data analyst, business intelligence analyst, machine learning engineer
suits: students who enjoy finding patterns in numbers and like statistics as well as programming

## bscyber
name: BS Cyber Security
summary: A four-year degree on protecting computer systems, networks and data from attacks.
studies: programming, computer networks, operating systems, cryptography, network security, ethical hacking, digital forensics, security policy
skills: finding and fixing security weaknesses, network defence, analytical thinking
careers: cyber security analyst, penetration tester, security engineer, digital forensics investigator
suits: students who like thinking like a hacker, solving puzzles and protecting systems

## bsit
name: BS Information Technology
summary: A four-year degree on running and supporting the computer systems organisations depend on - networks, servers, cloud and web systems.
studies: programming, networking, system administration, databases, web technologies, cloud computing, IT project management
skills: setting up and maintaining systems, networking, troubleshooting, web development
careers: network engineer, cloud engineer, system administrator, IT support, web developer
suits: students who like keeping systems running and solving practical technical problems, with less heavy maths
